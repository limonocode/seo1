# Архив

Сюда сложены **неактуальные заглушки** раннего репозитория (2017),
чтобы корень остался пакетом skills, а история не потерялась.

## 2017-stub

| Файл | Что это |
|------|---------|
| `2017-stub/meta` | пустой HTML-каркас (`<!DOCTYPE html>…`) |
| `2017-stub/robots.txt` | текст-заглушка `text here` — **не** robots |
| `2017-stub/sitemap` | такая же заглушка — **не** sitemap.xml |

Не используй эти файлы как образец `robots.txt` / sitemap.
Актуальные правила — в `skills/yandex-tech` и чеклистах.

## Исторический файл в корне

Файл с именем ровно `Без названия-3` лежит **в корне репозитория**,
не в архиве. Это тот же HTML-каркас, что когда-то назывался так
в коммите `c557e5e`. Его **нельзя** менять, переименовывать,
удалять или перезаписывать.

`meta` в этом архиве — поздний rename того же blob; корень хранит
оригинальное имя.
