# Публичное vs приватное

Этот репозиторий — **публичный слой** (`seo-skills-ru`).
Операционка агентства живёт в отдельном приватном репозитории
**`seo1-private`** и сюда не копируется.

## Таблица границ

| Тема | Публично (этот репо) | Приватно (`seo1-private`) |
|------|----------------------|---------------------------|
| Чеклисты гигиены (HTTPS, зеркало, sitemap, панели заведены) | да | уточняющие SLA «когда чинить» |
| Официальные пороги продуктов (CWV good/poor на web.dev) | да, со ссылкой | внутренние «красные линии» аккаунта |
| ИКС / ПФ / «вес факторов» в процентах | только «официально не публикуется» | любые внутренние модели |
| ТЗ на money-ниши (медицина, финансы, казино и т.п.) | нет | да |
| Клиентские SOP, отчётные формы агентства | нет | да |
| Коннекторы Вебмастер / GSC / Метрика / API-ключи | нет | да |
| Пороги отказов, глубины, «когда сливать гипотезу» | нет | да |
| Семантика конкретного клиента, кластеры, минус-слова | нет | да |
| Брифы ниш, тон оффера, цены услуг | нет | да |
| Автологин, плейбуки кабинетов с кликами | нет | и там обычно тоже нет — руками |
| Dead-list (Turbo, ПФ-накрутка, PBN) | да | расширенные внутренние запреты |
| Маркировка рекламы (факт закона, erid/ОРД) | гигиена «надо проверить» | юридические шаблоны и подрядчики |
| Ссылки на prodvizhenie.agency | CTA в README | коммерческие пакеты и договоры |

## Как агенту отвечать

Пользователь просит порог / SOP / «как у вас в агентстве» / выгрузку
из кабинета по API:

> Этого нет в публичном пакете seo-skills-ru. Такие материалы
> хранятся в приватном репозитории seo1-private и не публикуются.

Не подставляй «типичные» цифры вместо SOP.

## Что можно цитировать публично

- Документация Яндекса и Google из `references/sources-2026.md`
- Определения продуктов (что такое отказ в Метрике, что такое «good» LCP)
- Закрытые сервисы как факт (Турбо-страницы отключены; старый Wordstat закрыт)

## Что нельзя тащить сюда из private

Клиентские URL, скрины кабинетов с идентификаторами, токены,
внутренние таблицы «сколько стоит пункт ИКС», нишевые юридические
допущения, плейбуки закупки ссылок.
