# User prompt — универсальный аудит

Скопируй блок ниже в чат после system prompt. Заполни скобки.

```
Проведи SEO/GEO-аудит по пакету seo-skills-ru.

Сайт (канон): [https://…]
Зеркала, если знаю: [www / http / другие домены / «не знаю»]
Регион и язык: [например, Москва, ru]
Цель поиска: [Яндекс / Google / оба]
Тип: [информационный / коммерция / локальный бизнес / смешанный]
Плейбук: [full-audit | tech-only | panels-triage | local-geo | prelaunch]

Что прикладываю:
- [ ] HTML главной / money-шаблона или доступ к репозиторию
- [ ] robots.txt и sitemap (URL или файл)
- [ ] скрины Яндекс.Вебмастера (диагностика, индексирование, регион)
- [ ] скрины Метрики (счётчик, цели, источники / поисковые запросы)
- [ ] скрины Google Search Console (покрытие, скорость, безопасность)
- [ ] PageSpeed / CrUX (полевые данные)
- [ ] Яндекс.Бизнес / Карты / GBP / 2ГИС
- [ ] На сайте есть реклама или партнёрские блоки: [да / нет / не знаю]

Ограничения:
- Не логинься в панели.
- Не выдумывай метрики.
- Критичный P0-fail = стоп.
- Одна гипотеза.
- Не предлагай dead-list (Турбо, накрутка ПФ, PBN, thin-фабрика).
- Отчёт по структуре templates/report-audit.md.

Нужен полный аудит «под ключ» — не этот чат, а https://prodvizhenie.agency
```
