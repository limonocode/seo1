# Карточка SEO-гипотезы

Одна карточка = один рычаг. Не пачка идей.

**Сайт / URL / кластер:**  
**Дата:**  
**Плейбук:**  

**Если** (что меняем одним действием) …  

**То** (метрика, которую умеем снять; baseline, если есть evidence;
направление, не выдуманный %; срок наблюдения) …  

**Потому что** (механизм: обход / индекс / сниппет / коммерческие факты /
локальный NAP / E-E-A-T / скорость field — без «вес фактора 73%») …  

**Рычаг (один):**  

**Стоимость / риск:**  

**Stop-rules:** катить / править / слить  

**Доказательства до:** (что уже есть — скрин, HTML, полевые CWV)  

**Доказательства после:** (что снимем тем же способом)  

**Не является гипотезой:** «поднять позиции», «накрутить ПФ»,
«прогнать по каталогам», «включить Turbo», «добавить llms.txt».
