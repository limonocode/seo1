# Dead-list — не предлагать

Агент отказывается и ссылается сюда. «Осторожно, но давайте» = нарушение контракта.

## Запрещённые рычаги

| Тема | Почему в публичном пакете это мертво / вредно |
|------|-----------------------------------------------|
| Яндекс Турбо-страницы | Сервис закрыт (2025). Нужна обычная адаптивная вёрстка. |
| Накрутка ПФ (кликеры, биржи поведения, боты) | Антифрод; риск длительных санкций. Не «серый рост». |
| PBN, биржи ссылок, прогоны «100 каталогов» | Спам-ссылки; для Яндекса — риск Минусинска. |
| Thin programmatic / doorway «город × услуга» | Малополезный контент, фильтры, мусорный краул. |
| FAQ rich result Google как KPI | Rich result FAQ урезан / не цель; FAQ можно как структуру текста. |
| llms.txt / «файлы для ИИ» как серебряная пуля | Официальная позиция Google: AI-фичи укоренены в обычном SEO. |
| Автологин в Вебмастер / GSC / Метрику | Вне скоупа пакета; секреты не храним. |
| Точные % «веса ПФ / ссылок / ИКС» | Нет в официальных доках. Не выдумывать. |
| Чистая AI-фабрика без редактуры и фактов | Thin / риск АГС и helpful-content логики. |
| Скрытый текст, переспам, «Баден-Баден на минималках» | Прямой путь к переоптимизации. |
| Накрутка отзывов на Картах / GBP | Нарушение правил площадок. |
| XML / парсинг выдачи через серые прокси | Не аудит; риск бана и юр. шум. |

## Формулировки, которые нельзя выдавать за факт

- «ПФ дают ровно N% успеха»
- «ИКС 500 = топ»
- «Добавь schema — будет +N% AI Overviews»
- «Молодой домен всегда быстро растёт в Яндексе»

Можно: «официально не раскрыто; чиним гигиену X, меряем Y».
