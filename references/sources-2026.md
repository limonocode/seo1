# Источники 2026 (публичные)

Сначала официальная документация. Блоги — только как `[не офиц.]`.
Проверяй дату страницы: продукты закрываются.

## Яндекс [офиц.]

- Вебмастер: https://yandex.ru/support/webmaster/
- ИКС (индикатор, не «прямой фактор» в доке): https://yandex.ru/support/webmaster/ru/site-quality-index
- Робот и robots.txt: https://yandex.ru/support/webmaster/ru/robot-workings/robots-txt
- Метрика: https://yandex.ru/support/metrica/
- Wordstat (актуальный интерфейс): https://wordstat.yandex.ru/
- Wordstat API: https://yandex.ru/support2/wordstat/en/content/api-wordstat
- Яндекс.Бизнес: https://yandex.ru/support/business-priority/
- Поиск API (платный Cloud, не бесплатный XML): см. Yandex Cloud Search API

Факт продуктов, который агент должен помнить:

- Бесплатный Яндекс.XML закрыт (2023) → облачный API.
- Старый Wordstat отключён (11.08.2025) → актуальный wordstat.yandex.ru.
- Турбо-страницы не использовать (закрытие трансляции в выдаче, 2025).

## Google [офиц.]

- Search Central: https://developers.google.com/search/docs
- AI-фичи и SEO: https://developers.google.com/search/docs/fundamentals/ai-optimization-guide
- Системы ранжирования (описание, не веса): https://developers.google.com/search/docs/appearance/ranking-systems-guide
- Organization JSON-LD: https://developers.google.com/search/docs/appearance/structured-data/organization
- robots.txt: https://developers.google.com/search/docs/crawling-indexing/robots/intro
- Search Console: https://support.google.com/webmasters
- Core Web Vitals: https://web.dev/articles/vitals
- PageSpeed Insights: https://pagespeed.web.dev/

CWV «good» (field, p75): LCP ≤ 2.5s, INP ≤ 200ms, CLS ≤ 0.1.

## Закон РФ о рекламе [офиц. контур]

- 38-ФЗ «О рекламе» — текст на pravo.gov.ru / консультантах.
- Разъяснения ФАС по маркировке интернет-рекламы — актуальный раздел фас.gov.ru.
- Конкретный ОРД и шаблоны erid — у выбранного оператора, не в этом репо.
