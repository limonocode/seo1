# Skill: требования Яндекса

## Зачем

Сверить сайт с тем, что Яндекс **публично** просит: понятный контент,
доступность роботу, честные коммерческие сведения, нормальная мобильная
версия. Не «угадать формулу».

## Когда

- Полный аудит, прелоунч, коммерческий сайт.
- Пользователь спрашивает «что Яндекс хочет в 2026».

## Когда не

- Просьба накрутить ПФ или «вес факторов».
- Нужны нишевые ТЗ (медицина, финансы) — это `seo1-private`.

## Шаги

1. Прочитай `checklists/p0-gate.md`. Если техника FAIL — вернись
   в `yandex-tech`, не оценивай «качество текстов».
2. Money-страницы: основной ответ/оффер в HTML, не ниже бесконечного баннера.
3. Коммерция (если тип commercial / local):
   - цены или явный диапазон **текстом**
   - контакты / NAP
   - доставка, оплата, возврат — если это магазин/услуга
   - реквизиты / юрлицо, если пользователь ведёт B2B-оферту
4. Смысл, не плотность: ключ в title/H1 ок; простыня вхождений —
   риск переоптимизации (фильтр «Баден-Баден» описан Яндексом как
   реакция на некачественный SEO-текст). Не ставь «минус N позиций».
5. ИКС в Вебмастере — **индикатор**, не KPI и не прямой рычаг.
   Справка: support webmaster / site-quality-index.
6. Экосистема: для локалки и бренда проверь, есть ли Яндекс.Бизнес
   (`yandex-geo-neuro`). Не обещай «Neuro возьмёт вас, если…».
7. Турбо не предлагать. Mobile = адаптив / responsive.
8. Зафиксируй пробелы в таблице отчёта. Одна гипотеза максимум
   (обычно: «вынести цену и условия в текст» или «убрать SEO-простыню»).

## Входы

- HTML money-шаблона
- Тип сайта и регион
- Скрины Вебмастера (фильтры, ИКС — опционально)

## Выходы

- Список расхождений с публичными ожиданиями
- Не «оценка качества 8.4/10»

## Типичные находки

- Цена только на скрине баннера, в HTML пусто.
- «Уникальный SEO-текст» 2–4 тыс. знаков без оффера и фактов.
- Телефон в футере картинкой, в карточке Карт — другой.
- Title про Москву, регион Вебмастера — вся Россия (или наоборот).
- ИКС обсуждают как KPI вместо заявок.

## Как писать evidence

```
URL: https://example.com/price
Цитата HTML: <p>цена по запросу</p>
Дата: 2026-09-22
Вывод: коммерческий факт не раскрыт текстом
```

Не подставляй чужой домен из головы. Нет HTML — `❓`.

## Ошибки агента

- Оценить «качество» баллами.
- Посоветовать уплотнить ключи.
- Пропустить P0 и сразу писать контент-план.

## Стоп

- Пользователь просит точный % ПФ / коммерческих факторов.
- Тексты просят сгенерировать тоннами без фактов — dead-list.
- Критичный P0 fail.
