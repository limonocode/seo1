# Skill: ошибки панелей

## Зачем

Перевести формулировки кабинетов в действия. Одна группа — одно
действие, не простыня URL.

## Когда

- Плейбук `panels-triage` или красные отчёты в полном аудите.

## Когда не

- Нет скринов — пустая таблица со статусом `нет данных`.

## Шаги

1. Выпиши причины **как в кабинете** (не переводи сразу в «гуглоязык»).
2. Схлопни в группы: noindex, disallow, канон на другой хост,
   soft-404, 3xx цепочка, 4xx, 5xx, duplicate, discovered not indexed,
   redirect error, server error.
3. На 1–2 URL из группы проверь снаружи: headers, HTML, robots,
   canonical (то, что пользователь дал или что видно без авторизации).
4. Класс:
   - подтверждено снаружи → править сайт
   - только кабинет → переобход / ждать / неясно
   - ложноположительное → объяснить, не трогать
5. Заполни `templates/panel-errors-table.md`.
6. Приоритет: 5xx и неверный канон хоста > noindex на проде >
   crawl trash > «discovered not indexed» без тех. дыр.
7. Не обещай, когда URL вернётся в индекс.

## Входы

- Скрины Вебмастера / GSC
- Выборочный HTML
- Чеклисты `yandex-webmaster.md`, `google-gsc.md`

## Выходы

- Таблица групп
- Список URL-примеров (только те, что дали)

## Мини-выход (вставить в отчёт)

```
Кабинеты: Вебмастер / GSC / оба
Групп: N (не URL)
P0 группы: канон хоста / 5xx / noindex на проде
Таблица: templates/panel-errors-table.md
```

## Типичные находки

- Одна причина в Вебмастере, другая в GSC на том же URL — обе правды.
- «Discovered not indexed» при жирном sitemap из фасетов.
- Canonical на www, панель на apex — группа «канон хоста».
- Пользователь прислал один скрин без легенды фильтра.

## Как писать evidence

Группа → цитата кабинета → один пример URL → внешний статус.
Если примера URL нет, группа всё равно валидна, колонка URL пустая.

## Ошибки агента

- Развернуть 5 тысяч строк экспорта в отчёт.
- Назначить срок «через 3 дня в индексе».
- Вылечить «not indexed» текстами при `noindex`.

## Стоп

- Дописывать «у вас 12 847 исключённых», если числа не было.
- Смешивать счётчики Яндекса и Google в одну колонку «индекс».
