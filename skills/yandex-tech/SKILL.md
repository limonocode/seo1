# Skill: техника Яндекса

## Зачем

Убедиться, что робот получает тот же смысл, что человек, на одном хосте.

## Когда

- Любой плейбук после или вместе с P0.
- Tech-only и прелоунч — основной skill.

## Когда не

- Задача чисто про тексты при уже зелёной технике — тогда
  `yandex-requirements`.

## Шаги

1. Сними канон: какой URL отдаёт 200 без редиректа.
2. Проверь http→https, www/без, хвосты `/index.php` — всё должно
   сходиться **одним** 301 на канон.
3. `robots.txt`: доступен, синтаксис понятен роботу, не закрывает
   CSS/JS, нужные разделы открыты. Справка Яндекса по robots — в
   `references/sources-2026.md`.
4. `noindex` vs `Disallow`: закрытое в robots не стоит ждать в индексе;
   для снятия из индекса нужен доступный URL с `noindex` (логика та же
   у Google; для Яндекса сверь справку Вебмастера).
5. Sitemap: URL канона, 200, не служебные, не пагинация фильтров.
6. HTML: title, H1, цена/лид — в исходнике, не только после React-hydrate.
7. Mobile: viewport, читаемый текст, клики не 1px. Турбо не использовать.
8. Коды: soft-404 (200 + «нет такой») — чинить.
9. Отдай находки в `checklists/p0-gate.md` и `code-perf-security.md`.

## Входы

- Живой URL или HTML
- robots.txt, sitemap.xml
- Заголовки ответа (если пользователь дал `curl -I` — ок; сам не атакуй)

## Выходы

- Список тех. блокеров
- Что можно проверить без Вебмастера, а что нельзя

## Типичные находки

- Цепочка http → https://www → https → https?/utm.
- `Disallow: /` забыли снять после запуска.
- Sitemap на 10k URL фильтров, money-страниц 20.
- Контент в `window.__DATA__`, пустой `<div id="app">`.
- 200 на несуществующих URL («мягкий 404»).

## Как писать evidence

Хватит статус-кода, итогового URL и короткой цитаты из HTML
или первой строки `robots.txt`. Не прикладывай полные дампы.

Пример: «GET / → 301 Location: https://canon.example/ ; GET канон → 200».

## Ошибки агента

- Лечить индекс новыми текстами при кривом зеркале.
- Рекомендовать Turbo «для мобильного SEO».
- Закрыть CSS/JS в robots «чтобы сэкономить краул».

## Стоп

- Нет смысла советовать «500 новых URL», пока канон и SSR сломаны.
- Не пиши эксплойты, не сканируй агрессивно чужой прод.
