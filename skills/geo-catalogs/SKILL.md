# Skill: каталоги (не ссылочный спам)

## Зачем

Проверить согласованность уже существующих карточек. Добавлять
площадки — только точечно и по смыслу.

## Когда

- Локальный аудит после NAP на сайте и Картах.
- Пользователь прислал список «нас прописали здесь».

## Когда не

- «Нужно ссылок». Это не skill закупки.
- Предложение биржи / автопрогона.

## Шаги

1. Сначала сайт + Яндекс.Бизнес + (если Google) GBP + 2ГИС.
   Каталоги — хвост, не голова.
2. Инвентаризация: площадка / URL карточки / NAP / живая ли страница.
3. Расхождения телефона и адреса — чинить, не плодить новые карточки.
4. Мёртвые дубли бренда — пометить «объединить / удалить», если
   пользователь владелец.
5. Не рекомендовать спам-каталоги, футеры-фермы, «вечные» биржи.
6. 2–3 нишевых справочника с трафиком людей — можно обсудить
   как **гипотезу присутствия**, не как ссылочный вес.
7. Отзывы: отвечать можно; покупать нельзя.

## Входы

- Список URL от пользователя
- Эталонный NAP
- Чеклист `geo-nap-catalogs.md`

## Выходы

- Таблица площадок со статусом сверки
- Что снять / что оставить

## Мини-выход (вставить в отчёт)

```
Эталон NAP: …
Я.Бизнес / Карты / GBP / 2ГИС: сведены? 
Прочие площадки: N проверено / N расхождений
Новые регистрации: не предлагались / точечно [имя]
```

## Типичные находки

- 80 прогонов 2018 года, половина 404, NAP старый.
- Дубль карточки с опечаткой в бренде.
- «Каталог» с биржевым анкором в описании.
- 2ГИС свежий, сайт со старым адресом.

## Как писать evidence

Площадка | URL карточки | NAP ок? | страница жива? | действие.
Не добавляй площадки, которых пользователь не называл,
«потому что обычно регистрируют».

## Ошибки агента

- Назвать каталоги «ссылочной стратегией».
- Предложить пакет из 100 площадок.
- Игнорировать расхождение NAP ради новой регистрации.

## Стоп

- PBN, биржи, прогоны, скрытые ссылки.
- Авторегистрация ботом.
