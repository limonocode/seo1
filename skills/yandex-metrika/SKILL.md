# Skill: Яндекс.Метрика

## Зачем

Проверить, что визиты с канона пишутся в один счётчик и что есть
цель, пригодная как north star. Метрика **не** инструкция по накрутке.

## Когда

- Полный аудит, прелоунч, разбор «трафика нет / много отказов».
- Нужно понять, можно ли вообще мерить гипотезу.

## Когда не

- Запрос «сделай поведенческие». Это dead-list.
- Нет счётчика и нет HTML — не выдумывай номер и цели.

## Шаги

1. Найди код счётчика в HTML канона (или скрин «код установлен»).
2. Сверь: счётчик не сидит только на www, пока канон без www (и наоборот).
3. Цели: хотя бы одна бизнес-цель (форма, клик по телефону, thank-you).
   «Просмотр 3 страниц» как единственная цель — слабо для гипотезы.
4. Источники → ПС: есть ли органика Яндекса/Google в принципе.
   Нет данных / новый счётчик — так и скажи.
5. Поисковые запросы: используй только то, что на скрине.
   Не дополняй «наверное ещё вот эти ключи».
6. Аномалии: ровный график ботов, всплеск из пустого реферера —
   пометь «подозрение на мусор/накрутку», не обвиняй без evidence.
7. Вебвизор — только если смотрите UX money-страницы. Не проси
   записи чужих сессий в git.
8. Напоминание: отказ в продукте Метрики ≠ «фактор ранжирования N%».

## Входы

- HTML или контейнер тегов
- Скрины счётчика, целей, источников
- Чеклист `checklists/yandex-metrika.md`

## Выходы

- Статус счётчика и целей
- Можно ли мерить гипотезу этой Метрикой
- Явный запрет накрутки в next actions, если пользователь её ждал

## Типичные находки

- Счётчик только в GTM на десктопе, mobile-шаблон без тега.
- Два счётчика: старый на поддомене, новый на каноне.
- Целей нет, отчёт «отказы высокие» без бизнес-события.
- Реклама уже крутится, а счётчик поставили вчера.

## Как писать evidence

```
Счётчик: номер с скрина (если дан)
Где в HTML: строка / контейнер GTM
Цель: «Отправка формы /contact» — есть / нет
Источники ПС: скрин, период
```

Не публикуй сырые IP, записи Вебвизора и имена клиентов.

## Ошибки агента

- Перевести «отказ» в фактор ранжирования.
- Сравнивать Метрику и GA4 как одну истину.
- Предложить «улучшить ПФ» без изменения страницы.

## Стоп

- Любой план имитации визитов, кликеров, «сервисов ПФ».
- Выгрузка сырых визитов с ПДн в отчёт.
