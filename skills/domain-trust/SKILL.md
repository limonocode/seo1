# Skill: домен и доверие

## Зачем

Не строить гипотезы роста на домене из-под спама и не путать
«возраст» с гарантией топа.

## Когда

- Новый/купленный домен, переезд, подозрение на аффилиат.
- Полный аудит, блок «домен».

## Когда не

- Просьба «нарастить ИКС» или купить доноров.

## Шаги

1. Спроси историю: кто владел, был ли переезд, стоял ли другой сайт.
2. Wayback / то, что пользователь уже посмотрел: тематика прошлого.
   Сам не обязан парсить веб-архив, если нет входа.
3. Несколько доменов одной фирмы в одной выдаче — риск склейки
   (аффилиат). Формулы нет; фиксируй факт «два витринных домена»
   и спроси роль каждого.
4. Панели: malware, фильтры — из скринов, не из слухов.
5. Ссылки: только по выгрузке пользователя. Биржевой слепок —
   «не наращивать», не «чистить сервисом X» без private SOP.
6. ИКС / сторонние рейтинги — индикаторы. В north star не ставить.
7. Переезд: карта 301, оба кабинета, оба счётчика.

## Входы

- Домен, рассказ владельца
- Опционально выгрузка ссылок / Wayback
- `checklists/domain-trust.md`

## Выходы

- Риски истории (есть / нет / не знаем)
- Нужен ли отдельный плейбук переезда (описать шаги без SLA)

## Мини-выход (вставить в отчёт)

```
Домен: …
История: известна / неизвестна (источник)
Другие витрины той же фирмы: …
Фильтры/malware в панелях: …
ИКС/DR в KPI: нет
```

## Типичные находки

- Купленный домен из-под виагры, 301 на новую тематику «для веса».
- Два витринных домена одной клиники в одном городе.
- Переезд без карты URL, оба домена в индексе.
- ИКС ставят целью квартала.

## Как писать evidence

Источник истории (рассказ владельца / Wayback-скрин / WHOIS-скрин)
+ дата. Нет источника — «история неизвестна», не «домен чистый».

## Ошибки агента

- Продать дроп как стратегию.
- Объявить аффилиат без двух доменов в evidence.
- Считать высокий сторонний рейтинг доверием Яндекса.

## Стоп

- PBN, дроп-домены «под нишу» как стратегия.
- Точные обещания «молодой домен взлетит».
